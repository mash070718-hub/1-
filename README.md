# Library of Limbus

Library of Ruina의 어두운 서가, 금빛 장식, 붉은 강조색을 참고한 개인 림버스 컴퍼니 도서관입니다. 게임의 공식 한국어 이름과 이미지를 갖춘 도감에서 직접 티어와 평가를 작성할 수 있습니다.

## 1차 완성본 사용

터미널이나 파일 다운로드 없이 사용하려면 [GitHub Pages 활성화 안내](docs/PUBLISH.md)에 따라 저장소의 웹 배포를 켜세요. 배포 파일 `docs/index.html`에는 사이트, 305개 항목의 데이터와 공식 썸네일이 모두 포함됩니다.

로컬 파일로도 사용할 수 있습니다. `docs/index.html`을 PC에 저장해 일반 브라우저에서 열면 설치나 실행 중 인터넷 연결은 필요하지 않습니다.

1. 수감자와 인격 · E.G.O 분류를 선택합니다.
2. 카드를 누르고 **평가 작성**에서 장점, 단점, 운용 방법을 기록합니다.
3. 콘텐츠별 티어를 선택하고 **기록 저장**을 누릅니다.
4. **새 기록**으로 개인 덱을 만들고 편성 인격과 편성번호를 연결합니다.
5. 상단 백업 버튼에서 **백업 다운로드**를 눌러 JSON 파일도 보관하세요.

독립 HTML의 저장 지원은 브라우저에 따라 달라집니다. 같은 브라우저에서 같은 파일을 사용하고, 파일 이름·위치를 바꾸거나 브라우저 데이터를 삭제하기 전에 백업하세요. 다른 기기에서는 JSON 백업을 가져올 수 있습니다. 로그인이나 자동 동기화는 포함하지 않습니다.

## 수록 자료

**2026-10-06에 대조한 공개 게임 자료 기준으로 인격 189개, E.G.O 116개, 총 305개**를 포함합니다. 수감자 12명 모두 수록하며, 최근 출시일은 2026-10-01, 한국어 자료 버전은 1.116.0입니다. 과거 시즌과 한정 출시 항목도 포함합니다. 미출시·적·테스트·스토리 전용 데이터는 제외합니다.

게임의 공식 한국어 문자열과 원화를 커뮤니티 미러에서 대조했습니다. 모든 권리는 Project Moon에 있으며 이 사이트는 개인 팬 프로젝트입니다. [정확한 출처, 커밋, 수감자별 개수와 갱신 절차](docs/CATALOG_SOURCES.md)를 기록했습니다. 앱에서도 **자료 출처와 수록 범위** 버튼으로 확인할 수 있습니다.

일반 웹 버전은 원화와 썸네일 **610장**을 로컬에 포함합니다. 독립 HTML은 용량을 줄이기 위해 공식 썸네일 305장을 포함하며 약 8.5 MiB입니다. 이미지를 외부 서버에서 실시간으로 가져오지 않습니다.

티어와 장단점은 모두 빈 개인 기록으로 시작합니다. 실제 게임 평가를 추측해서 채우지 않습니다. 공식 한국어 이름과 수감자는 유지하고, 개인 소개·태그·노트·추천 E.G.O·사용 덱을 편집할 수 있습니다. 공식 도감 항목은 **평가 초기화**로 개인 평가만 지울 수 있습니다.

## 기능

- 인격 · E.G.O · 덱 분류, 12명 수감자 필터, 이름 · 수감자 · 태그 검색
- 스토리, 경험치 · 끈 채광, 거울던전, 사영전투, 1 · 2 · 6호선별 독립된 S/A/B/C/D 티어와 미평가 상태
- 상세 노트, 추천 E.G.O와 사용 덱 연결, 편성 인격과 편성번호 표시·복사
- 덱 편성과 인격의 사용 덱을 양방향으로 연결
- 개인 기록 추가·수정·삭제, 평가 작성·미평가 상태 필터와 더 보기
- 브라우저 로컬 저장, JSON 백업 · 검사 후 복원
- 이전 버전의 노트·티어·태그·덱 연결 보존과 신규 도감 자동 병합
- 모바일 화면, 키보드 탭 이동, 읽기 쉬운 평가 창

## 개발 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다. 현재 환경은 Node.js 24, Python 3.12, 시스템 Chromium으로 검증했습니다.

```sh
cd /workspace/1-
npm ci --cache /workspace/.npm
npm run dev -- --port 5173 --strictPort
```

각 클라우드 작업은 이미 격리되어 있으므로 기존 체크아웃을 사용합니다. 별도 Git worktree는 필요하지 않습니다. 서버 주소는 실행한 환경의 접속 방식에 따라 확인하세요.

```sh
npm run build             # 타입 검사와 프로덕션 정적 파일 생성
npm run preview           # 빌드 결과 확인
npm test                  # 저장·마이그레이션·도감·이미지 파일 테스트
npm run test:e2e           # 실제 Chromium에서 사용자 흐름 검증
npm run check:catalog      # 305개 항목과 610장 이미지의 무결성 검사
npm run build:standalone   # 다운로드할 독립 HTML 생성
```

독립 HTML의 기본 출력은 `/workspace/library-files/Library-of-Limbus.html`입니다. 다른 출력 경로도 지정할 수 있습니다.

```sh
node scripts/build-standalone.mjs /tmp/Library-of-Limbus.html
```

브라우저 테스트는 기본적으로 `/usr/bin/chromium`을 사용합니다. 다른 경로는 `CHROMIUM_EXECUTABLE_PATH`로 지정하세요.

## 저장과 자료 갱신

개인 기록은 `localStorage`의 `library-of-limbus:v1`에 보관합니다. 게임 카탈로그와 이미지 데이터는 별도 파일에 있어 도감을 갱신해도 개인 평가를 덮어쓰지 않습니다. 이전 v1 JSON 백업도 가져올 수 있으며 누락된 도감 항목은 자동으로 추가합니다.

백업 가져오기는 파일을 검사한 뒤 **가져오기 확인**을 눌렀을 때만 기존 기록을 교체합니다. 깨진 저장소와 잘못된 JSON은 원본을 보존합니다. 저장 오류가 나오면 편집 창의 내용을 유지하고, 정상 저장을 확인한 후 닫으세요.

자료 갱신은 [출처 문서](docs/CATALOG_SOURCES.md)의 스크립트를 사용합니다. 이미지에는 SHA-256·원본 주소·치수 정보가 포함되며 TLS와 파일 검증을 유지합니다. 갱신 후 독립 HTML도 다시 빌드해야 새로운 도감이 포함됩니다.

## 검증과 배포 범위

데이터·마이그레이션 테스트 **36개**, 실제 브라우저 테스트 **12개**가 통과했습니다. 도감 전체 이름·수감자·이미지, 평가 수정·초기화, 이전 기록 보존, 콘텐츠별 티어, 덱 연결, 백업·복원과 390px 모바일 화면을 검증했습니다. 웹 버전의 610장 모두 브라우저에서 디코딩되며 독립 HTML은 외부 이미지·API 요청 없이 동작합니다.

독립 HTML은 같은 파일을 임시 HTTP 서버에서 열어 저장·수정·백업·새로고침 유지까지 확인했습니다. 이 클라우드 Chromium의 관리 정책은 `file://` 탐색을 차단하므로 직접 파일 열기 검증은 수행하지 못했습니다. 파일 자체는 외부 의존성 없이 일반 브라우저의 디스크 실행을 위한 형태로 구성했습니다.

`dist/`를 정적 웹 호스팅에 배포할 수 있습니다. 공개 인터넷 주소로의 배포는 아직 수행하지 않았습니다. 웹 버전에는 로그인 제한이 없으며 방문자별로 자신의 브라우저에 기록을 저장합니다. 여러 기기 자동 동기화나 비공개 로그인 사이트가 필요하면 인증과 서버 저장소를 추가해야 합니다.
