거울던전 사진 저장소 설정

처음 한 번만 설정하면 덱마다 직접 플레이한 데미지 스크린샷을 최대 3장까지 첨부할 수 있습니다. 기존 Supabase 프로젝트를 그대로 사용합니다.

1. Supabase SQL Editor 열기

Supabase 설정 화면 열기 ↗

현재 사이트와 연결한 프로젝트의 SQL Editor → New query를 엽니다.

2. 아래 SQL을 복사해서 실행

새 쿼리에 전체를 붙여넣고 Run을 누르세요. Success. No rows returned가 나오면 완료입니다.

사진 저장소와 접근 규칙만 추가합니다. 기존 평가·덱·관리자 계정은 지우거나 변경하지 않습니다. 같은 SQL을 다시 실행해도 기록은 보존됩니다.

3. 사진 첨부하고 게시하기

  1. 사이트를 새로고침하고 관리자 로그인합니다.
  2. 거울던전 → 덱 선택 → 기록 수정으로 들어갑니다. 새 덱이면 새 거울던전 기록을 누릅니다.
  3. 데미지 스크린샷 → 스크린샷 파일 선택에서 사진을 최대 3장 선택합니다. PNG·JPG·WebP 파일을 지원하며 한 장의 원본 크기는 20MB 이하여야 합니다.
  4. 업로드가 끝나면 사진마다 층수·기프트·피해량 등 설명을 적을 수 있습니다.
  5. 기록 저장 → 게시하기 → 공개 게시 확인을 누릅니다. 방문자는 덱 상세 화면에서 사진을 눌러 확대해서 볼 수 있습니다.

저장과 공개 범위

사진 파일은 Supabase에 저장되며 브라우저 용량을 차지하는 평가 백업에는 사진 연결 정보와 설명만 넣습니다. 게시 전 사진은 관리자만 볼 수 있습니다. 게시된 덱에 포함된 사진만 방문자에게 공개됩니다.

‘첨부 제거’는 편집 중인 덱에서 사진을 뺍니다. 게시하기 전까지 기존 공개 사진은 유지됩니다. 기존 백업 복원을 위해 원본 저장소의 사진 파일은 자동 삭제하지 않습니다. Supabase 저장소에서 파일을 직접 지우면 그 사진이 들어 있는 백업도 복원할 수 없습니다.

유료 기능 가입은 필요하지 않으며 기존 Supabase 무료 플랜의 저장 공간과 전송량 한도 안에서 사용합니다.
